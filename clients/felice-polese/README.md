# Pack di riferimento — Felice Polese

Questo è il cliente **live** da cui è nato il template.

- Identità / copy: `profile.ts` (letto da `clients/active.ts` → `lib/site-config.ts`)
- Listino / orari seed: `lib/catalog.ts`
- Prodotti: `lib/products.ts`
- Foto locale: `lib/salon-photos.ts`
- Video: `lib/site-videos.ts`
- Media: `public/assets/**`

Per un nuovo salone **non modificare** questo pack: crea uno slug nuovo con `scripts/scaffold-client.mjs`.
