COME ANDARE LIVE (tu devi fare questi 4 passi)
----------------------------------------------
  1. Supabase
     Crea un progetto su https://supabase.com
     SQL Editor → incolla ed esegui  supabase/migrations/001_schema.sql
     (unico schema: tabelle barbers, services, appointments + RLS.
      Non esiste una seconda migration 001_appointments.)
     Copia Project URL e service_role key.

  2. Resend
     Crea un account su https://resend.com
     Genera una API key. Verifica il dominio (o usa l'indirizzo di test).
     Imposta RESEND_FROM (es. Polese Barbershop <prenotazioni@tuodominio.it>).

  3. Variabili ambiente (Vercel → Project → Settings → Environment Variables)
     NEXT_PUBLIC_SITE_URL=https://polesebarbershop.vercel.app
     SUPABASE_URL=...
     SUPABASE_SERVICE_ROLE_KEY=...
     NEXT_PUBLIC_SUPABASE_URL=...   (stesso URL)
     NEXT_PUBLIC_SUPABASE_ANON_KEY=...
     RESEND_API_KEY=...
     RESEND_FROM=...
     ADMIN_EMAIL=info@polesebarbershop.it
     ADMIN_PASSWORD=...  (password forte, almeno 4 caratteri)

  4. Deploy
     Vercel collega il repo e fa il build (`npm run build`).
     Verifica: prenota un Taglio Pro, ricevi email + .ics, apri /admin.
