POLESE BARBERSHOP
=================

Brand: FELICE POLESE — Barberia d'élite a Benevento
Nuovo locale: Corso Dante n. 45, 82100 Benevento BN

SITO LIVE
---------
  https://polesebarbershop.vercel.app

REPOSITORY GITHUB
-----------------
  https://github.com/mandalinomc-ai/polesebarbershop

AVVIO LOCALE
------------
  npm install
  npm run dev
  Apri http://localhost:3000

  Windows: doppio click su AVVIA.cmd

PRENOTAZIONI
------------
  Wizard in stile Fresha nella sezione #prenota (e pagina /prenota).
  Primo giorno prenotabile: max(oggi, 1 settembre 2026).
  Conferma via email (Resend) e WhatsApp (Twilio).
  Promemoria WhatsApp 30 minuti prima (QStash).

  Copia .env.example in .env.local e inserisci le chiavi.
  Applica la migration Supabase: supabase/migrations/001_appointments.sql
